# Pilot 知情同意说明（2 人测试）

请参与者阅读以下内容，口头同意即可；如需要，可打印签字。

1. **目的**：这是一个课程项目（FYP）的可行性测试，目的是验证触屏手势能否被稳定采集，以及能否区分本人和模仿者。

2. **采集内容**：只采集你在平板屏幕上画手势时的轨迹坐标、时间戳、笔压力、接触面积和笔倾角。不采集姓名、照片、声音、账号或设备中的其他数据。

3. **匿名**：数据只用编号（如 P01、P02）标识，报告中不会出现你的真实姓名。

4. **用途**：数据仅用于本项目分析与论文，不用于商业用途，不公开发布可识别个人的原始数据。

5. **自愿与退出**：参与完全自愿；你可以在任何时候停止，并要求删除已采集的数据。

6. **风险**：测试只涉及在平板上画几次手势，预计 15 分钟左右，风险极低；如果手部疲劳可随时休息。

7. **联系**：如有疑问，请联系项目学生【姓名/邮箱】或导师 Prof. Gerhard Hancke。
